# 숫자 야구 기능 목록

## 게임 시작
- [ ] 게임 시작 문구를 출력한다.
- [ ] 1~9 중 서로 다른 숫자 3개를 컴퓨터 정답으로 생성한다.

## 사용자 입력
- [ ] 숫자 입력 안내 문구를 출력하고 입력받는다.
- [ ] 입력값이 1~9로 이루어진 서로 다른 숫자 3자리인지 검증한다.
- [ ] 길이 오류, 중복, 0, 문자, 공백이 포함된 입력은
  IllegalArgumentException을 발생시키고 종료한다.

## 판정과 출력
- [ ] 숫자와 위치가 같으면 스트라이크로 계산한다.
- [ ] 숫자는 같지만 위치가 다르면 볼로 계산한다.
- [ ] 볼과 스트라이크가 모두 없으면 낫싱을 출력한다.
- [ ] 결과는 볼, 스트라이크 순서로 출력하고 개수가 0인 항목은 생략한다.
- [ ] 정답을 맞힐 때까지 같은 정답으로 입력과 판정을 반복한다.

## 게임 종료와 재시작
- [ ] 3스트라이크이면 정답 안내 문구를 출력한다.
- [ ] 재시작 안내 문구를 출력하고 선택을 입력받는다.
- [ ] 1이면 정답을 새로 생성하여 게임을 다시 시작한다.
- [ ] 2이면 애플리케이션을 종료한다.
- [ ] 그 외 입력이면 IllegalArgumentException을 발생시키고 종료한다.
