# 숫자 야구
컴퓨터가 정한 서로 다른 3자리 숫자를 사용자가 맞히는 게임

## 📋 기능 목록

### 1. 입력
- [x] 사용자로부터 문자열을 입력받는다.

### 2. 입력 검증
- [x] 사용자 입력에 대한 기본 조건을 만족해야한다.
  - `null`값이 아니여야 한다.
  - 빈값 혹은 빈칸이 아니여야 한다.
- [x] 숫자 입력은 아래 조건을 모두 만족해야 한다.
  - 3자리여야 한다.
  - 1~9 사이의 숫자로만 이루어져야 한다.
  - 서로 다른 숫자여야 한다.
- [x] 재시작/종료 입력은 `1` 또는 `2`여야 한다.

### 3. 게임 로직
- [x] 1~9 사이의 서로 다른 숫자 3개로 정답을 생성한다.
- [x] 입력한 숫자와 정답을 비교해 스트라이크 개수를 센다.
  - 같은 자리에 같은 숫자
- [x] 입력한 숫자와 정답을 비교해 볼 개수를 센다.
  - 다른 자리에 같은 숫자
- [x] 스트라이크가 3개이면 게임을 끝낸다.
- [x] 재시작(1)이면 새 정답을 만들어 다시 시작하고, 종료(2)이면 종료한다.

### 4. 출력
- [x] 게임 시작 문구를 출력한다.
  - `숫자 야구 게임을 시작합니다.`
- [x] 숫자 입력 안내 문구를 출력한다.
  - `숫자를 입력해주세요 : `
- [x] 판정 결과를 출력한다.
  - `1볼 1스트라이크` / `1볼` / `1스트라이크` / `낫싱`
- [x] 게임 종료 문구를 출력한다.
  - `3개의 숫자를 모두 맞히셨습니다! 게임 종료`
- [x] 재시작/종료 안내 문구를 출력한다.
  - `게임을 새로 시작하려면 1, 종료하려면 2를 입력하세요.`

### 5. 예외 처리
- [x] 잘못된 입력이면 `IllegalArgumentException`을 발생시키고 종료한다.

### 6. 요구 사항
- [x] 사용자가 입력하는 값은 `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용한다.
- [x] Random 값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용한다.

### 7. 책임 분리
- controller : 게임의 흐름을 제어
  - `GameController` : 입력 → 판정 → 출력의 게임 진행 흐름을 제어한다.
- domain : 게임에 대한 규칙과 동작을 구현
  - `BaseballGame` : 한 판의 정답을 가지고 있고, 입력된 숫자에 대한 판정을 요청한다.
  - `BaseballNumbers` : 게임에서 사용되는 숫자들을 생성하고 검증하며 입력된 숫자에 대한 결과를 판정을 하여 반환한다.
  - `GameResult` : 판정 결과(스트라이크, 볼 개수)를 담고, 게임의 상태를 판정한다.
  - `GameCommand` : 재시작/종료 선택 
  - `GameRuleConstant` : 게임 규칙과 관련된 상수들을 정의한다.
- exception : 게임에서 발생하는 오류 정의
  - `BaseballErrorMessage` : 오류 메세지 정의
  - `BaseballGameException` : 게임 예외 정의
- view : 프로그램의 입출력을 제어 
  - `InputView` : 사용자 입력을 받는다.
  - `OutputView` : 안내 문구와 결과를 출력한다.
  - `InputValidator` : 입력 형식 검증 (null/blank 검증)
  - `OutputMessage` : 안내 및 출력 문구 정의
