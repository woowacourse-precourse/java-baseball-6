# 숫자 야구
컴퓨터가 정한 서로 다른 3자리 숫자를 사용자가 맞히는 게임

## 📋 기능 목록

### 1. 입력
- [ ] 문자열을 입력받는다.
- [ ] 재시작/종료 여부를 입력받는다.

### 2. 입력 검증
- [ ] 숫자 입력은 아래 조건을 모두 만족해야 한다.
  - 3자리여야 한다.
  - 1~9 사이의 숫자로만 이루어져야 한다.
  - 서로 다른 숫자여야 한다.
- [ ] 재시작/종료 입력은 `1` 또는 `2`여야 한다.

### 3. 게임 로직
- [ ] 1~9 사이의 서로 다른 숫자 3개로 정답을 생성한다.
- [ ] 입력한 숫자와 정답을 비교해 스트라이크 개수를 센다.
  - 같은 자리에 같은 숫자
- [ ] 입력한 숫자와 정답을 비교해 볼 개수를 센다.
  - 다른 자리에 같은 숫자
- [ ] 스트라이크가 3개이면 게임을 끝낸다.
- [ ] 재시작(1)이면 새 정답을 만들어 다시 시작하고, 종료(2)이면 종료한다.

### 4. 출력
- [ ] 게임 시작 문구를 출력한다.
  - `숫자 야구 게임을 시작합니다.`
- [ ] 숫자 입력 안내 문구를 출력한다.
  - `숫자를 입력해주세요 : `
- [ ] 판정 결과를 출력한다.
  - `1볼 1스트라이크` / `1볼` / `1스트라이크` / `낫싱`
- [ ] 게임 종료 문구를 출력한다.
  - `3개의 숫자를 모두 맞히셨습니다! 게임 종료`
- [ ] 재시작/종료 안내 문구를 출력한다.
  - `게임을 새로 시작하려면 1, 종료하려면 2를 입력하세요.`

### 5. 예외 처리
- [ ] 잘못된 입력이면 `IllegalArgumentException`을 발생시키고 종료한다.

### 6. 요구 사항
- [ ] 사용자가 입력하는 값은 `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용한다.
- [ ]Random 값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용한다.

### 7. 책임 분리
- `GameController` : 입력 → 판정 → 출력의 게임 진행 흐름을 제어한다.
- `BaseballGame` : 한 판의 정답을 가지고 있고, 입력된 숫자에 대한 판정을 요청한다.
- `BaseballGameJudge` : 정답과 입력을 비교해 스트라이크/볼을 계산한다.
- `GameResult` : 판정 결과(스트라이크, 볼 개수)를 담는다.
- `BaseballNumbers` : 서로 다른 1~9 숫자 3개 (생성 시 게임 규칙 검증)
- `NumberGenerator` : 정답용 숫자 3개를 생성한다.
- `GameCommand` : 재시작/종료 선택 (1 또는 2 검증)
- `InputView` : 사용자 입력을 받는다.
- `OutputView` : 안내 문구와 결과를 출력한다.
- `InputValidator` : 입력 형식 검증 (null/blank, 숫자 여부)
